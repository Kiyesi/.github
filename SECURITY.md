# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.

Instead, email **security@kiyesi.dev** with:

- a description of the flaw and its impact
- steps to reproduce, or a proof of concept
- the affected version, if known

You can also use GitHub's private vulnerability reporting ("Report a vulnerability" on the repository's Security tab) where it is enabled.

We will acknowledge your report, keep you updated while we investigate, and credit you when the fix is released, unless you prefer to stay anonymous. Please give us reasonable time to fix the issue before you disclose it publicly.
